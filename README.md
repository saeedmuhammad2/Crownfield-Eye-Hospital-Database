# Crownfield-Eye-Hospital-Database
Individual database development project for Crownfield Eye Hospital using MySQL.

# Project Overview
This project involves designing, developing, and testing a relational database for Crownfield Eye Hospital using MySQL 8.0.46 and MySQL Workbench.

# Database Features
- Patient and clinician management
- Appointment management
- Diagnosis records
- Prescription and medicine management
- Follow-up management
- Database auditing
- User roles and access permissions
- Data encryption

# SQL Files
1. 01_database_schema.sql – Creates the database tables and relationships.
2. 02_data_insertion.sql – Inserts synthetic sample data.
3. 03_database_testing.sql – Tests database operations and transactions.
4. 04_procedure_and_triggers.sql – Creates stored procedures and triggers.
5. 05_database_security.sql – Implements database roles, permissions and encryption.
6. 06_individual_queries.sql – Contains six individual SQL activities for Student 3.
